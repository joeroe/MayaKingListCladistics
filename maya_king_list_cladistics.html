This document describes a cladistic analysis of 72 Maya king lists. The analysis was performed in R version 4.5.1 (2025-06-13) (R Core Team 2025).

There are several methods we can use to generate a dendrogram of this data: the simplest, hierarchical clustering, only considers the relative ‘dissimilarity’ between specimens; the unrooted phylogenetic tree introduces the assumption that these dissimilarities are the result of a process of copying-with-error; the rooted phylogenetic tree further assumes that specimen K1372 is the most conservative copy.

Unrooted phylogenetic tree

If we incorporate the assumption that dissimilarities between specimens arose through a process of copying with error (either from each other or from the original), we can generate a more informative tree using phylogenetic methods. We use the ‘branch and bound’ algorithm (Hendy and Penny 1982) to find the most parsimonious trees, i.e. those that require the least number of copying errors. Phylogenetic analyses were conducted using the R packages ape (Paradis & Schliep 2019) and phangorn (Schliep 2011).

This results in 2 most parsimonious trees. From these we derive the consensus tree, which only includes clades that are found in all most parsiminous trees.

The consistency index and retention index are two methods of quantifying how well the observed data fits a phylogenetic model. Both are on a scale of 0 to 1, with 1 being the most ‘tree-like’. For the consensus tree, the consistency index is 0.67 and the retention index is 0.48. This is within the typical range for cultural phylogenies (Collard et al. 2006).

Rooted phylogenetic tree

Further assuming that K1372 is the most conservative copy allows us to ‘root’ the trees above, i.e. ensure that this specimen is the first branch.

Ancestral trait reconstruction

Using the rooted consensus tree, we can reconstruct the characteristics of the hypothetical archetypes at the base of each clade, including the basal clade – the putative original. We use the maximum parsimony (MPR) algorithm.

We can also use this to visualise the evolution of a specific trait on the tree (e.g. Figure 4).
